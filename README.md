# 🧊 Айсберг Українського Репу

Інтерактивна веб-мапа та особистий щоденник дослідження сучасної сцени українського репу: від поп-хітів та радіочартів до найглибшого мемного андеграунду.

Базується на вірусному мем-айсбергу та особистому експерименті з прослуховування всіх представлених артистів.

---

## 🎧 Мій метод дослідження

Кожного виконавця я знаходив на **YouTube Music** і слухав його **3 найпопулярніші пісні від початку до кінця**, незалежно від того, подобався мені трек чи ні. 

Якщо артист зачіпав і викликав щирий інтерес — я занурювався глибше, слухав альбоми та дискографію, додаючи бонусні треки до своїх нотаток.

---

## 🗺️ Рівні Айсбергу (58 артистів, 200+ треків)

Сцена розділена на 4 концептуальні рівні занурення:

* **📈 Рівень 0: Топ-чарти** *(5 артистів)* — Мільйонні перегляди, широкі маси, поп-реп та радіо-хіти (*alyona alyona, Kalush, Skofka, Yarmak, qatoshi*).
* **🏔️ Рівень 1: Вершина айсберга** *(13 артистів)* — Відомі імена, мейнстрім та впізнаваний саунд (*Clonnex, Otoy, jockii druce, паліндром, нестор, МС Петя, Naperexresti, NORD DIVISION тощо*).
* **🌊 Рівень 2: Під водою** *(20 артистів)* — Середня глибина, самобутній вайб, нішевий хайп та альтернативний хіп-хоп (*Oi FUSK, blessbaby, Ницо Потворно, Krechet, Freel, Довгий пес, STAS AZARENKO, Райчу, G Grizzie тощо*).
* **🕳️ Рівень 3: Безодня** *(20 артистів)* — Глибокий андеграунд, мікросцени, треп/клауд, деконструкція та мем-реп (*йо, Lizzzard, Phate Xick, OKAYSAMMY, Рома факти, LIL SMALL, AQUAZOII, дейside, 35cake, LeChapo, CBFire тощо*).

## ✨ Можливості сайту

- **📱 Оптимізація під мобільні телефони:**
  - **Стікі-панель керування:** пошук та фільтри закріплені у верхній частині екрана з ефектом розмиття (Glassmorphism).
  - **Горизонтальний скрол категорій:** швидкий вибір рівнів в один дотик без нагромадження кнопок.
  - **Розумний вибір режиму:** на смартфонах за замовчуванням вмикається зручний режим вертикальних карток (`Картки`).
  - **Адаптивний модальний перегляд:** зручне читання відгуків та гортання треків свайпами/кнопками на телефонах.
- **🔍 Миттєвий розумний пошук:** фільтрація за назвою артиста, окремими треками, емоціями або текстом рецензії в реальному часі.
- **🗂️ Два режими перегляду:**
  - **🧊 Айсберг:** візуальні рівні глибини з інтерактивними пігулками та міні-аватарками артистів.
  - **🗂️ Картки:** галерея повноформатних карток зі співвідношенням 16:9, списком прослуханих пісень, тегами вердиктів та враженнями.
- **🖼️ 95%+ покриття обкладинками:** прямі CDN-прев'ю у високій якості без CORS-блокувань та зовнішніх серверів. Для рідкісного мікро-андеграунду створено процедурний CSS-фолбек у вигляді неонової вінілової платівки.
- **▶️ Прямий перехід у YouTube Music:** швидкі посилання на сторінку виконавця або на конкретний трек в один клік.
- **📝 Локальний редактор заміток:** можливість редагувати або доповнювати враження та зберігати їх у браузері (`localStorage`).
- **🗺️ Оригінальний айсберг:** вбудоване модальне вікно для перегляду первинного мем-зображення.

## 🛠️ Стек технологій

Проєкт створено за принципом **Zero Dependencies / Maximum Performance**:
- **HTML5:** Семантична розмітка, нативні теги `<dialog>` для модальних вікон.
- **CSS3:** Сучасний адаптивний дизайн (Flexbox, CSS Grid, змінні CSS, Glassmorphism, `overflow-x: clip`, стилізація під темну тему з унікальним неоновим сяйвом для кожного рівня).
- **Vanilla JavaScript (ES6+):** Модульні IIFE-замикання, делегування подій, збереження в `localStorage` без важких фреймворків чи сторонніх бібліотек.
- **Мережева автономність:** Відсутність рантайм `fetch()` запитів дозволяє сайту працювати як через локальний файл (`file://`), так і на будь-якому статичному хостингу.

## 🚀 Як відкрити та запустити

1. Клонувати репозиторій:
   ```bash
   git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ>
   cd ukrainian_rap
   ```
2. Відкрити файл `index.html` у будь-якому браузері (Safari, Chrome, Firefox, Edge):
   - Можна просто двічі клікнути по `index.html`.
   - Або запустити простий локальний сервер:
     ```bash
     npx serve .
     # або
     python3 -m http.server 8080
     ```

Також проєкт готовий до публікації на **GitHub Pages** (Settings -> Pages -> Deploy from a branch `main` / `root`).
